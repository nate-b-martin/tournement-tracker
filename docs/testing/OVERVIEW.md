# Testing Overview

## Testing Strategy

| Layer | Tool | Location | Purpose |
|-------|------|----------|---------|
| **Unit Tests** | Vitest + React Testing Library | `tests/unit/` | Test components and hooks in isolation |
| **E2E Tests** | Playwright | `tests/e2e/` | Test full user flows in a browser |

## Unit Tests

### Framework

- **Runner**: [Vitest](https://vitest.dev/) (configured in `vite.config.ts`)
- **DOM**: jsdom (virtual browser environment)
- **Library**: React Testing Library (`@testing-library/react`)
- **Mocking**: Vitest's `vi.fn()`, `vi.mock()`

### Setup File

**File**: [`src/test-utils/setup.ts`](../src/test-utils/setup.ts)

Runs before all tests. Sets up jsdom, configures Testing Library matchers.

### Running Unit Tests

```bash
npm run test              # All unit tests
npm run test:watch        # Watch mode
npm run test tests/unit/components/DataTable.test.tsx  # Single file
```

### Test Files

| File | What It Tests |
|------|---------------|
| [`tests/unit/components/DataTable.test.tsx`](../tests/unit/components/DataTable.test.tsx) | DataTable rendering, sort clicks, pagination callbacks, empty state, actions visibility, search input, filter chips |
| [`tests/unit/components/PaginationControls.test.tsx`](../tests/unit/components/PaginationControls.test.tsx) | Page nav buttons, page info text, page size selector, edge cases (first/last page, single page) |
| [`tests/unit/hooks/usePagination.test.ts`](../tests/unit/hooks/usePagination.test.ts) | Pagination math (totalPages, startIndex, endIndex, hasPrevious, hasNext) |

### Mocking Pattern

**Mock data**: `src/mocks/data/` — mockPlayers, mockTeams
**Mock hooks**: `src/mocks/hooks/` — useMockPlayers (for isolated component tests)

```typescript
// Example: testing DataTable
import { fireEvent, render, screen } from "@testing-library/react";
import { vi } from "vitest";

const onSort = vi.fn();
render(<DataTable data={items} columns={columns} onSort={onSort} ... />);
fireEvent.click(screen.getByText("Name"));
expect(onSort).toHaveBeenCalledWith("name");
```

### Coverage

Current coverage targets are not configured. Run `vitest run --coverage` to see coverage if needed.

## E2E Tests

### Framework

- **Tool**: [Playwright](https://playwright.dev/)
- **Browser**: Chromium (configurable in `playwright.config.ts`)
- **Auth**: Clerk test credentials with global setup

### Configuration

**File**: [`playwright.config.ts`](../playwright.config.ts)

- Web server: starts `npm run dev` automatically
- Port: 3000
- Test directory: `tests/e2e/`
- Auth state: `playwright/.clerk/user.json` (generated by global setup)

### Running E2E Tests

```bash
npm run test:e2e              # Headless
npm run test:e2e:ui           # UI debug mode (Playwright Trace Viewer)
npm run test:e2e:headed       # Visible browser
npx playwright test tests/e2e/auth.spec.ts  # Single file
```

### Authentication Flow

See [`tests/E2E_TESTS.md`](../tests/E2E_TESTS.md) for full details. Summary:

1. **Global setup** (`tests/e2e/global-setup.ts`) signs in once using Clerk test credentials
2. **Storage state** is saved to `playwright/.clerk/user.json`
3. **All tests** use this saved state (auto-loaded via `storageState` in playwright config)
4. **Unauthenticated tests** explicitly clear storage state

### Test Files

### Test Fixtures

**File**: [`tests/e2e/fixtures/auth.ts`](../tests/e2e/fixtures/auth.ts)

Lightweight test export (`test` and `expect`). No sign-in logic — relies on storage state from global setup.

### Prerequisites for E2E Tests

Required in `.env.local`:

```
VITE_CLERK_PUBLISHABLE_KEY=pk_test_...
CLERK_SECRET_KEY=sk_test_...
CLERK_TEST_EMAIL=test-user@example.com
CLERK_TEST_PASSWORD=password
```

The global-setup reads `CLERK_TEST_EMAIL` and `CLERK_TEST_PASSWORD` (not `CLERK_EMAIL` or `ADMIN_CLERK_EMAIL`).

### Regenerating Auth State

```bash
rm -f playwright/.clerk/user.json
npx playwright test tests/e2e/global-setup.ts
```

## Adding New Tests

### Unit Test Checklist

1. Create test file in `tests/unit/` mirroring source structure
2. Import component/hook from `@/` alias
3. Mock Convex hooks if needed (use `src/mocks/`)
4. Use `render`, `screen`, `fireEvent` from Testing Library
5. Use `vi.fn()` for callbacks
6. Run with `npm run test <path>`

### E2E Test Checklist

1. Ensure dev server is running
2. Ensure Clerk test credentials are in `.env.local`
3. Add test file in `tests/e2e/`
4. Use page objects from `tests/e2e/pages/`
5. Tests start authenticated by default
6. For unauthenticated tests: `test.use({ storageState: { cookies: [], origins: [] } })`
7. Run with `npm run test:e2e`
